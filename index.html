Bank Management System — Enterprise Architecture

System Purpose & Context

An enterprise desktop banking application developed with JavaEE layered architecture and JavaFX graphical user interface, designed to handle multi-teller workflows, transactional financial operations, and customer account administration with high reliability.

Functional Modules

  • Multi-Role Access Control: Distinct privileges and dashboards for Bank Tellers, Branch Managers, and Customer views.
  • ACID Transaction Processing: Deposits, withdrawals, and inter-account fund transfers implemented with strict SQL database transaction rollback safeguards (`commit()` / `rollback()`).
  • Customer KYC & Account Management: Account opening, balance checking, profile verification, and dynamic interest calculation.
  • Immutable Audit Log: Complete ledger and timestamped audit logs for every transaction and administrator action.

Layered Enterprise Architecture

Presentation Layer : JavaFX FXML + Custom CSS (Modern Desktop UI) │ Service / Controller: Java Business Logic & Session Validation │ Data Access Layer : JDBC DAO Pattern + PreparedStatements │ Database Tier : Relational SQL Database (ACID Compliant)
