Optimizers from Scratch — Adam & AdaGrad

Project Overview

A first-principles mathematical implementation of gradient descent optimization algorithms from scratch using pure NumPy — without relying on automatic differentiation or autograd frameworks like PyTorch or TensorFlow.

Mathematical & Algorithmic Highlights

  • AdaGrad (Adaptive Gradient): Dynamic parameter-specific learning rates based on accumulated squared gradients, dampening oscillations for frequent features.
  • Adam (Adaptive Moment Estimation): Combined first-moment vector (momentum) and second-moment vector (uncentered variance) with mathematical bias correction for initial timesteps.
  • Loss Surface Experiments: Visualized convergence trajectories on complex multimodal 2D/3D test loss functions (e.g., Rosenbrock & Rastrigin benchmarks).
  • Vectorized Performance: Highly optimized NumPy array operations leveraging broadcasting for efficient batch computations.

Algorithm Flow

Objective Loss Function ➔ Compute Analytical Gradients (NumPy) ➔ Exponential Moving Averages (m_t, v_t) ➔ Bias Correction (m̂_t, v̂_t) ➔ Adaptive Parameter Update: θ_{t+1} = θ_t - η / (√v̂_t + ε) * m̂_t

Regex → NFA → DFA Automata Engine

Engine Architecture

A theoretical computer science engine built in Java that transforms regular expressions into Non-deterministic Finite Automata (NFA) and converts them into Deterministic Finite Automata (DFA) through fundamental formal language algorithms.

Core Theoretical Algorithms

  • Thompson's Construction: Regex parsing with operator precedence, concatenation insertion, and recursive NFA fragment generation with ε-transitions (handles `*`, `+`, `?`, `|`).
  • Dynamic Alphabet Extraction: Dynamically scans the regex to extract literal alphabet symbols rather than hardcoding.
  • Subset Construction: Systematic power set conversion from NFA to DFA using transitive ε-closure calculation and state-set grouping.
  • Simulation & Visual Export: Interactive step-by-step string acceptance simulation, ASCII transition matrix generation, and exportable Mermaid state diagrams.

Pipeline Mechanics

Regular Expression ➔ Infix Operator Precedence ➔ Thompson's Construction (NFA) ➔ ε-Closure Computation ➔ Subset Construction ➔ Deterministic Finite Automaton (DFA) ➔ String Acceptance Simulator & Mermaid Diagram Export

Arithmetic Expression & Tree Parsing Engine

Pipeline Overview

A computer science data structures engine implementing parsing algorithms, tree traversals, and custom collision-resolved hash tables in Java.

Algorithmic Highlights

  • Lexical Tokenizer: Converts arithmetic string streams into typed tokens (operands, operators, parentheses).
  • Dijkstra's Shunting-yard Algorithm: Converts infix expressions to postfix (Reverse Polish Notation) with strict operator precedence handling.
  • Binary Expression Tree: Constructs syntax trees from postfix tokens and executes 4 tree traversals (In-order, Pre-order, Post-order, Level-order/BFS).
  • Custom Hash Table Storage: Dual implementations supporting both Double Hashing (open addressing) and Separate Chaining collision resolution.

Processing Flow

Infix Expression String ➔ Lexical Tokenizer ➔ Shunting-yard Algorithm ➔ Postfix RPN Notation ➔ Binary Expression Tree Construction ➔ 4 Traversals (In/Pre/Post/Level) ➔ Hash Table Storage with Double Hashing
