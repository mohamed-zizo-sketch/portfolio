## 🚀 Live Preview & Running Locally

### Option 1: Direct Browser Launch
Simply open `index.html` in any modern web browser (Google Chrome, Microsoft Edge, Firefox, Brave, Safari):
```powershell
Start-Process "index.html"
```

### Option 2: Via Local Server (e.g. VS Code Live Server or Node.js)
If you are running the project root `server.js`:
```powershell
npm start
```
Then navigate to:
```
http://localhost:3000/portfolio/
```

### Option 3: Deploy to GitHub Pages or Vercel
This portfolio is completely self-contained with no build steps or heavy dependencies required.
You can push the `portfolio` folder to a GitHub repository and turn on **GitHub Pages** (Settings ➔ Pages ➔ Deploy from Branch `/root` or `/docs`) for an instant live URL.
